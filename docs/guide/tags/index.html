Tags

EJS templates are HTML with JavaScript embedded inside delimiter tags. By default the tags open with <% and close with %>. Each variant controls whether code runs, whether its result is printed, and how it is escaped.

Tag reference

Section titled “Tag reference”
TagNameWhat it does
<%ScriptletRuns control-flow JavaScript; produces no output.
<%_Whitespace-slurping scriptletLike <%, but strips all whitespace before it.
<%=Escaped outputPrints the value into the template, HTML-escaped.
<%-Unescaped outputPrints the raw value into the template (no escaping).
<%#CommentDoes nothing and prints nothing.
<%%LiteralOutputs a literal <%.
%>Closing tagPlain close.
-%>Newline-trimming closeTrims the newline immediately after the tag.
_%>Whitespace-slurping closeStrips all whitespace after the tag.

Tip

Always use <%- with include() to avoid double-escaping the included HTML.

Comments

Section titled “Comments”

<%# ... %> lets you annotate templates. The contents are never executed and never appear in the output.
