Why EJS?

Section titled “Why EJS?”

Use plain JavaScript

All templating languages grow to be Turing-complete. Cut out the middle-man and just use the JS you already know.

Fast development

No arcane new syntax, no preprocessing your data so it renders right. Write JS that emits the HTML you want.

Simple syntax

JavaScript in plain scriptlet tags: <% %> to run, <%= %> to print.

Speedy execution

EJS caches the intermediate JS functions for fast execution across V8 and other runtimes.
